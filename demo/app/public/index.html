kahvi playground

kahvi is a JavaScript engine written from scratch in Rust: parser, bytecode VM, garbage collector, regex engine and every built-in. The code you run here is evaluated by kahvi compiled to WebAssembly, in your browser, not by your browser's own JavaScript engine. The server that sent you this page is a Hono app running on kahvi too.
